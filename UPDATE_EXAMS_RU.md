# Экзаменационные варианты — локальное обновление ProPharm 0.28.8

Готово локально; сайт не опубликован. Исторический оригинал сохранён. Изменения находятся в `ProPharm/Код`.

## Данные и поведение

Шесть отдельных вариантов: первый — 141 вопрос; тесты 13, 14, 15, 16, 17 — соответственно 109, 120, 120, 120, 58. Всего 668 вопросов, 3276 вариантов ответа, 34 ресурса. Подтверждённые ключи есть у 606 заданий, 62 задания исключены из оценки с точными причинами дефектов источника. Это полный импорт согласованного финального архива, а не заявление, что все исходные задания исправимы.

`correctOptionIds` — авторитетный массив. В 23 заданиях несколько допустимых ответов; любой один засчитывается правильно. Пустой массив никогда не считается ошибкой. Вопрос 71 теста 14 сохранён без вариантов, с причиной отсутствия условия. В тесте 15 №17 и №105 показано только «Перевод уточнён по оригиналу»; исходный текст сохранён в метаданных. Полный ключ и приложение с 62 причинами: `docs/exam-variants/answer-key.html`, `.md`, `.json`.

Маршрут: `#tests/exam-variants`. Все вопросы варианта находятся на одной прокручиваемой странице. Красная подсветка появляется сразу. Результат определяется неизменным первым выбором; исправление выбора не стирает ошибку. Пропуски с ключом и вопросы без ключа учитываются отдельно. Повторы состоят только из первоначальных ошибок и имеют отдельные результаты. Сохранение разделено по пользователю и варианту. Перезагрузка и смена варианта сохраняют состояние; новое прохождение начинается после подтверждения. Изменившийся ключ делает старый черновик несовместимым, не переоценивая его молча. Запись из устаревшей второй вкладки отклоняется с сообщением.

Это существующий изолированный QA-механизм проекта: жёлтая полоса и вымышленный аккаунт. Он проверяет тот же интерфейс с локальным защищённым набором данных, без связи с Supabase. QA-копия создаётся рядом с проектом и не входит в пакет для публикации. Её нельзя публиковать.

## Авторизация и границы выпуска

`services`, `config`, `supabase`, `src/core/access.js` не изменены. Исходная авторизация и все прежние разделы сохранены. Новые данные помещены в существующий защищённый bundle tests; изображения используют прежний resolveAsset. В публичной dist вопросов и изображений нет. Сборка создаёт server-bundle и SQL по прежней схеме, но SQL не выполнялся и backend не менялся.

Новый bundle ещё не установлен в рабочий backend, поэтому проверка настоящего входа и получения нового контента с рабочего сервера не выполнена. Подготовленный пакет обновления не является опубликованной версией. Для будущего выпуска понадобится отдельное разрешение на публикацию и обновление серверного контента.

Точное название: `all 15 law questions mark the source key only after a choice, without scoring`.
Файл: `tests/quiz-feedback.test.mjs`, строка 49 (падающая проверка — строка 59).

Это не сбой новой модели экзаменационных вариантов.
